修改理财页面为真实的股票信息
1. 理财页面 所有 信息展示来源于一个单独的 db 文件（该文件可以在初始化目录完成生成、导入）
2. 该 db 文件中用于存储 大盘/单只股票 的历史信息
3. 股票信息获取可以参考 /d/Workspace/agent 中的 skill 或者 /mnt/d/Workspace/Resonance 中的代码
4. 页面上支持 选择股票 后，构建这个股票的历史信息（若 db 中已有，则无需重新构建），并进行展示，数据支持 by 股票进行移除、重新构建，默认拉取的股票历史信息时间为 20150101 - 现在，可以调整该时间范围
    - 数据构建支持一键重建、一键补齐（针对所有记录的股票/大盘，补齐 最后一条数据 到 现在的信息）
5. 股票 需要展示的历史信息主要包含，股价变化、MA5、MA30、PE 变化、PB 变化、股息率的变化，这些信息基于 K 线图展示，可筛选（PE 变化、PB 变化、股息率的变化 这些信息如果某个时间段缺失，则沿用上一段的数据，但是展示要加以区分）
6. 大盘信息 添加  两市成交额(万亿) 和 融资余额(万亿)，大盘 和 股票 信息分开 查看，大盘无需展示股票特有的信息
7. 结合个人财务db 中的股票买卖信息（以描述中的 code 为唯一关联值），在 股票的 K线图上展示我的买点和卖点
